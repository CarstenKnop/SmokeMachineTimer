# Legacy documents

These files describe **earlier designs** of the project and are kept for history only. They do **not** describe the
current firmware (FogLink 2) — see the documents one level up (`MANUAL.md`, `RADIO_PROTOCOL.md`, `SERIAL_PROTOCOL.md`).

| File | Describes |
|------|-----------|
| `ESP32_Remote_Control_Specification.md`, `ESP32_Timer_Specification.md`, `RemoteControl_SPECS.md`, `CALIBRATION_AND_NEXT_STEPS.md` | the first ESP‑NOW design (acknowledge‑everything protocol, EEPROM layout, `ReliableEspNow`) that FogLink 2 replaced |
| `DEV_NOTES.md`, `QRcode_Implementation.md`, `ProjectDescription.txt` | the original single‑device *SmokeMachineTimer* (Wi‑Fi access point, web page, QR code) whose firmware still lives in the repository root (`src/`, `platformio.ini`) |
